Star Lanes — installable web app (PWA)

To install on an iPad:
1. Upload this folder to any HTTPS static host (GitHub Pages, Netlify Drop, Cloudflare Pages).
2. Open the URL in Safari on the iPad.
3. Share button > Add to Home Screen. It then launches full screen and works offline.

If you edit any file, bump the CACHE name in sw.js so devices pick up the change.
